# 商品テキストの上限

HF-005への対策として、商品名は200 UTF-16コード単位、説明とメモはそれぞれ4000 UTF-16コード単位に制限します。作成・更新APIはモデル検証に加えてサービス層でも検証し、JSON本文の上限は64 KiBです。

一覧APIでは説明・メモをSQLの取得対象から除外し、既存のレスポンスの両フィールドにはnullを返します。詳細APIは従来どおり両フィールドを返します。現在の一覧UIは両フィールドを利用していません。

SQLの列はnvarchar(max)のまま維持し、新規・更新データにDATALENGTH <= 8000のCHECK制約を適用します。WITH NOCHECKで既存値を保持するため、移行時に切り捨てや既存データの一括検証は行いません。既存の超過データを通常更新する際は、説明とメモを上限内へ編集する必要があります。別の書き込み経路で超過値を含む行を更新する場合にも制約で拒否される可能性があります。

移行前に超過データ件数を確認し、所有者と相談して縮約・別保管する運用を推奨します。本PRは既存値を自動削除しません。SQL Server実機への移行はローカル検証環境では実施していないため、ステージングで確認してください。
